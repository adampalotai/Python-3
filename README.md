
# 🐍 Willkommen zum Python-Unterricht!

### `Python` – ein Werkzeug, kein Reptil

Python ist eine **`moderne, einfach zu lernende Programmiersprache`**, die weltweit von Millionen Menschen verwendet wird.  
Sie ist besonders bekannt für ihren klaren und leicht lesbaren Code – perfekt für den Einstieg, aber auch mächtig genug für professionelle Softwareentwicklung.

##### *Sogar Unternehmen wie Google, Instagram, Netflix und sogar NASA nutzen Python!*

Und obwohl du bei „Python“ vielleicht an eine Riesenschlange denkst: Der Name der Programmiersprache Python stammt von einer alten Comedy-Sketch-Serie der BBC namens **`Monty Python's Flying Circus`**.

Auf dem Höhepunkt ihres Erfolgs führte das Monty-Python-Team seine Sketches vor Live-Publikum auf der ganzen Welt auf, unter anderem im Hollywood Bowl.

Da Monty Python als einer der zwei fundamentalen Nährstoffe für Programmierer gilt (der andere ist Pizza), benannte der Schöpfer von Python die Sprache zu Ehren dieser TV-Show.


### Wer hat Python erschaffen?

Eines der erstaunlichsten Merkmale von Python ist die Tatsache, dass es sich tatsächlich um das Werk **`einer einzelnen Person`** handelt. Normalerweise werden neue Programmiersprachen von großen Unternehmen entwickelt und veröffentlicht, die viele Fachkräfte beschäftigen. Aufgrund von Urheberrechtsregeln ist es oft schwer, die beteiligten Personen namentlich zu nennen. Python ist hier eine Ausnahme.

Es gibt nicht viele Sprachen, deren Autoren namentlich bekannt sind. Python wurde von **`Guido van Rossum`** erschaffen, der 1956 in Haarlem (Niederlande) geboren wurde. Natürlich hat Guido van Rossum nicht alle Python-Komponenten alleine entwickelt und weiterentwickelt...

Die Geschwindigkeit, mit der sich Python auf der ganzen Welt verbreitet hat, ist das Ergebnis der kontinuierlichen Arbeit von Tausenden (oft anonymen) Programmierern, Testern, Anwendern (viele von ihnen sind keine IT-Spezialisten) und Enthusiasten. Dennoch stammt die allererste Idee – der Samen, aus dem Python spross – aus einem einzigen Kopf: Guidos.

##### Python begann als ein Hobby-Programmierprojekt


> *„Im Dezember 1989 suchte ich nach einem ‚Hobby‘-Programmierprojekt, das mich in der Woche um Weihnachten herum beschäftigen würde. Mein Büro (...) würde geschlossen sein, aber ich hatte einen Heimcomputer und sonst nicht viel vor. <br>Ich beschloss, einen Interpreter für die neue Skriptsprache zu schreiben, über die ich in letzter Zeit nachgedacht hatte: ein Nachfahre von ABC, der Unix-/C-Hacker ansprechen würde. <br><br>Ich wählte Python als Arbeitstitel für das Projekt, da ich in einer leicht respektlosen Stimmung war (und ein großer Fan von Monty Python's Flying Circus).“* – *Guido van Rossum*


### Python ist extrem vielseitig. Du kannst damit:

- Webseiten entwickeln (z. B. mit Flask oder Django)
- Spiele programmieren
- Daten analysieren und visualisieren
- Maschinenlernen und KI entwickeln
- Hardware und Roboter steuern (z. B. mit Raspberry Pi)
- Automatisierungen und Skripte schreiben


### Python zu lernen bedeutet, 
- **Probleme kreativ zu lösen**, 
- **logisch zu denken** und 
- **Technologien der Zukunft** zu verstehen.
